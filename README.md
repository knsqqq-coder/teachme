# Teach Me

Teach Me — Django жобасы: конспектті оқу карточкаларына айналдырып, SQLite-та сақтайды. Бұл оқу жұмысының localhost нұсқасы; қолданушы тіркеуі және иелік құқығын тексеру әлі жоқ.

## Мүмкіндіктер

- Тақырып пен конспектіні сервер жағында тексеру.
- DEMO режимінде дайын желілер конспектінен өзгермейтін үш карточка алу. Бұл нәтиже ИИ генерациясы емес.
- Қолжетімді API кілті мен модель бапталса, бөлек LIVE режимін іске қосу.
- Конспект пен карточкаларды SQLite-қа бір транзакциямен сақтау.
- Тұрақты `/sources/<pk>/` бетінде карточкаларды ашып қайталау. Жауапты көрсету үшін карточканы ашыңыз; F5 не серверді қайта іске қосу сақталған деректерді өшірмейді.

Дәйексөз конспект ішінде мәтіннің дәл барын тексереді. Ол жауаптың дұрыстығын немесе ақиқаттығын дәлелдемейді.

## Қажетті құралдар

Python және pip орнатылған болуы керек. Жобаның `.venv` виртуалды ортасын қолданыңыз. Бұл жоба SmartChef-тен бөлек.

### Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver 127.0.0.1:8000
```

Браузерде [http://127.0.0.1:8000/](http://127.0.0.1:8000/) ашыңыз. `8000` бос болмаса, серверді `127.0.0.1:8001` портымен іске қосыңыз. `DEBUG=True` тек жергілікті әзірлеуге арналған.

## DEMO режимі

Әдепкі режим — `demo`; `.env` файлы міндетті емес. Басты бетте берілген дайын конспектті жіберіңіз. Ол IP-адрес, DNS және маршрутизатор туралы үш алдын ала жазылған карточканы қайтарады; сыртқы API шақырылмайды. Басқа конспектті DEMO қабылдамайды және мәтінді формада қалдырып, түсінікті қате көрсетеді.

## Қосымша LIVE режимі

LIVE режимін тек өз Gemini API кілтіңіз және аккаунтыңызда қолжетімді модель болғанда баптаңыз. Құпия `.env` файлын жобаның түбіріне `.env.example` үлгісінен көшіріңіз де, мәндерін толтырыңыз:

```dotenv
TEACHME_MODE=live
GEMINI_API_KEY=өз_құпия_кілтіңіз
GEMINI_MODEL=аккаунтыңыздағы_модель_аты
GEMINI_TIMEOUT_SECONDS=25
```

`GEMINI_TIMEOUT_SECONDS` 1–60 секунд аралығында болуы керек. Қолданба модель жауабын қолданар алдында карточка санын, өрістерін, ұзындығын, қайталанған сұрақтарды және дәйексөздерді тексереді. Кез келген LIVE қатесі қауіпсіз хабарлама береді; DEMO-ға үнсіз ауыспайды. Баптауды өзгерткеннен кейін серверді қайта іске қосыңыз.

**API кілтін ешқашан Git-ке қоспаңыз.** `.env` және SQLite дерекқоры `.gitignore` ішінде. `.env.example` ішінде тек бос кілт үлгісі болуы тиіс.

## Тексеру командалары

Мыналар — жобаны іске қосқан адамның жергілікті ортада өзі орындайтын командалары. Бұл README-де тест саны немесе LIVE нәтижесі алдын ала болжанбайды.

Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test study
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run
```

macOS / Linux:

```bash
python manage.py check
python manage.py test study
python manage.py makemigrations --check --dry-run
```

## Негізгі URL мен файлдар

- `/` — конспект енгізу, DEMO карточкаларын алу және сақталған жинақтарға өту.
- `/sources/<pk>/` — SQLite-та сақталған конспект пен карточкаларды көру.
- `study/services.py` — DEMO/LIVE генерация режимдері мен карточка валидациясы.
- `study/models.py` — `Source` және оған байланысқан `Flashcard` модельдері.

Жоба localhost-та бір адамның оқуына арналған. Қолданушы аутентификациясы мен иелік тексеруі жоқ, сондықтан оны ашық интернетке орналастырмаңыз.
