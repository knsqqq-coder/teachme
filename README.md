# Teach Me

Teach Me — Django оқу жобасы: конспекттен оқу карточкаларын жасап, оларды SQLite-та сақтайды. Бұл — аккаунтсыз, бір адамның `localhost` ортасында қолдануына арналған жоба. Ашық интернетке орналастырмаңыз: қолданушы тіркеуі мен жазбалардың иесін тексеру әлі жоқ.

## Мүмкіндіктер

- Тақырып пен конспект серверде тексеріледі.
- Әдепкі DEMO режимі тұрақты үш дайын карточканы қайтарады; ИИ не сыртқы желі шақырылмайды.
- Қосымша LIVE режимін API кілті мен қолжетімді модельді өзіңіз баптаған кезде қолдануға болады.
- Конспект пен карточкалар SQLite дерекқорына бір транзакциямен жазылады.
- Сақталған жинақтың тұрақты `/sources/<pk>/` бетінде карточка сұрақтарын оқып, жауап пен дәйексөзді ашуға болады.
- Сұрақты, жауапты және дәйексөзді өңдеуге болады. Дәйексөз сол жинақтың конспектінде дәл кездесуі керек; сәтті өңдеуден кейін карточка қайта тексерілуі тиіс.
- Өшіру алдында растау беті шығады. Расталғанда бір карточка ғана өшеді.
- Студент карточканы конспектпен салыстырғаннан кейін «Тексерілді» деп белгілей алады немесе тексеруге қайтара алады.
- «Барлығы», «Тексеру керек» және «Тексерілген» сүзгілері ағымдағы жинақтың карточкаларын көрсетеді. Санауыштар бүкіл жинаққа қатысты.

Дәйексөз оның үзіндісі бастапқы конспектте барын ғана растайды; жауаптың дұрыстығын дәлелдемейді. Мазмұнын студент өзі конспектпен салыстырады. Белгі де мазмұнның автоматты тексерісі емес.

## Қажетті құралдар

Python орнатылған болуы керек. Бар жоба түбірінде `.venv` ортасын құрып, тәуелділіктерді орнатыңыз.

### Windows PowerShell

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py runserver 127.0.0.1:8000
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver 127.0.0.1:8000
```

Браузерде [http://127.0.0.1:8000/](http://127.0.0.1:8000/) ашыңыз. `8000` порты бос болмаса, `127.0.0.1:8001` қолданыңыз. `DEBUG=True` тек жергілікті әзірлеуге арналған.

## Конспекттен қайталауға дейінгі жол

1. Басты бетке тақырып пен кемінде 80 таңбалық конспект енгізіңіз.
2. Дайын желілер DEMO мәтінін жіберсеңіз, үш тұрақты карточка жасалып, конспектпен бірге SQLite-та сақталады. Өзге мәтінді DEMO қабылдамайды; LIVE бөлек баптауды қажет етеді.
3. `/sources/<pk>/` бетіне өтіп, алдымен сұраққа жауап ойлаңыз, содан кейін «Жауапты көрсету» арқылы жауап пен бастапқы конспектідегі дәйексөзді ашыңыз.
4. «Өңдеу» сілтемесімен сұрақты, жауапты не дәйексөзді түзетіңіз. Дәйексөз конспектте дәл болуы керек. Сәтті сақтаған соң тексерілген белгі алынады.
5. Түзетілген мазмұнды конспектпен салыстырып, «Карточканы тексердім» батырмасын басыңыз. Бұл белгі дерекқорда сақталады; оны кейін «Тексеруге қайтару» батырмасымен өзгертуге болады.
6. Сүзгілерден тексерілмегендерді немесе тексерілгендерді табыңыз. Санауыш әрқашан осы жинақтың барлық карточкасын санайды.
7. Карточканы жою қажет болса, «Өшіру» сілтемесін ашып, растау бетінде әрекетті бекітіңіз. Тек таңдалған карточка жойылады; конспект пен көрші карточкалар сақталады.

Бет жаңарту немесе серверді қайта іске қосу сақталған жинақты жоғалтпайды. Әр карточканы өңдеуге, өшіруге және белгілеуге арналған әрекеттер тек сол жинаққа әсер етеді.

## DEMO және LIVE

Әдепкі режим — `demo`; `.env` файлы міндетті емес. Басты беттегі дайын конспект IP-адрес, DNS және маршрутизатор туралы үш алдын ала жазылған карточканы береді. Бұл ИИ жасаған нәтиже емес және API шақырмайды.

LIVE — қосымша мүмкіндік. Оны қолдану үшін `.env.example` үлгісін жобаның түбіріне `.env` атымен көшіріп, өз мәндеріңізді орнатыңыз:

```dotenv
TEACHME_MODE=live
GEMINI_API_KEY=өз_құпия_кілтіңіз
GEMINI_MODEL=аккаунтыңызда_қолжетімді_модель
GEMINI_TIMEOUT_SECONDS=25
```

Уақыт шегі 1–60 секунд аралығында болуы керек. Баптауды өзгерткеннен кейін серверді қайта іске қосыңыз. Кілтті ешқашан GitHub-қа жібермеңіз; `.env` мен `db.sqlite3` `.gitignore` ішінде болуы тиіс. `.env.example` құпия кілтсіз қалсын. LIVE баптауы болмағанда DEMO қолдануға болады.

## Тексеру командалары

Төмендегі пәрмендерді жобаны іске қосатын адам өзі орындайды; бұл нұсқаулық олардың нәтижесін алдын ала болжамайды.

Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test study
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run
```

macOS / Linux:

```bash
python manage.py check
python manage.py test study
python manage.py makemigrations --check --dry-run
```

Тесттер уақытша тест дерекқорында жүреді; LIVE желілік шақыруын не API кілтінің жарамдылығын дәлелдемейді.

## Негізгі жолдар

- `/` — конспект енгізу және сақталған жинақтар тізімі.
- `/sources/<pk>/` — конспект, карточкалар, санауыштар мен сүзгілер.
- `/cards/<pk>/edit/` — карточканы өңдеу.
- `/cards/<pk>/delete/` — өшіруді растау беті.
- `/cards/<pk>/review/` — тек POST арқылы тексерілген күйді өзгерту.

## Жоба шектеулері

Қолданушы тіркеуі, иелік құқығын тексеру, мұғалім кабинеті және бірнеше адамға арналған қолжетімділік жоқ. Дәйексөз конспектте барын ғана көрсетеді; карточка жауабының ақиқаттығын студент тексеруі керек.
